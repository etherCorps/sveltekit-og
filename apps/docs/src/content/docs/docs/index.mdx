**SvelteKit OG** turns an HTML + CSS template or a Svelte component into an image, with no headless browser. Return it from a SvelteKit server route and you have a dynamic Open Graph image; call `renderImage` and you have the bytes for anything else — thumbnails, certificates, social cards for a CMS.

```ts title="src/routes/og.png/+server.ts"
import { ImageResponse } from '@ethercorps/sveltekit-og';

export const GET = () =>
	new ImageResponse(`<div style="display:flex;font-size:64px">Hello</div>`, { width: 1200, height: 630 });
```

## Two engines, one API

| | **Takumi** (default) | **Satori** |
| --- | --- | --- |
| Pipeline | HTML → image, in Rust compiled to WebAssembly (native on Node) | HTML → SVG with [Satori](https://github.com/vercel/satori), SVG → PNG with ReSVG |
| Formats | `png`, `jpeg`, `webp`, `ico`, `raw`, `svg` | `png`, `svg` |
| Fonts | built-in sans-serif, plus yours | yours, or a bundled Noto Sans fallback |
| CSS | flex, grid, gradients, shadows | flex only (Satori's subset) |
| Install | `takumi-js` | `satori` + `@resvg/resvg-wasm` |

You pick the engine per call with `engine: "takumi" | "satori"`; the options narrow to what that engine supports, and the same call works on the server and in the browser. See [Takumi](/docs/engines/takumi/) and [Satori](/docs/engines/satori/).

## Where it runs

Node, Bun, Deno, Cloudflare Workers and Pages, Vercel and Netlify functions — every runtime SvelteKit deploys to, on SvelteKit 2 and 3. The [Deploy](/docs/deploy/node/) pages cover each adapter. The [client entry](/docs/guides/client/) renders in the browser or a web worker with the same API.

## Features

- **Svelte components or HTML strings** as templates; Tailwind classes, inline styles and `<style>` blocks all work.
- **Typed props**: a component's props are checked at the call site.
- **Fonts** from Google Fonts, local files or any URL, resolved and cached for you.
- **Emoji** from Twemoji, OpenMoji, Noto and others.
- **Engines are optional**: install the one you use; a call to a missing engine tells you the exact command to run.
- **Errors carry a code** (`ENGINE_NOT_INSTALLED`, `FONT_LOAD_FAILED`, …) so you can handle them.
- **Pre-rendering**: generate every image at build time with SvelteKit's `prerender`.
